# Gaming Blocks

A simple resource pack that overlays a rainbow animation on ores and other blocks/items.
The original block is still recognizable — crystal parts (like diamonds) keep their real color, while only the surrounding texture gets the rainbow filter.

**[View on Modrinth](https://modrinth.com/resourcepack/gaming-blocks)**

## Features

- Supports **32+ blocks/items** (ores, raw materials, ancient debris, suspicious sand/gravel, powder snow, budding amethyst, etc.)
- Keeps the original texture detail and crystal colors, tinting only the surrounding area
- Affected blocks glow in the dark on their own, making them easier to spot and less likely to miss while mining
- **[Respackopts](https://modrinth.com/mod/respackopts)** support: toggle each block/item ON/OFF individually
- Organized into two tabs: "Overworld" and "Nether"

## Required Mods

This pack uses **[Respackopts](https://modrinth.com/mod/respackopts)** for per-block ON/OFF toggling. Without it, the pack will not work correctly (required).

Respackopts supports both **Fabric** and **NeoForge**. Basic dependencies:

- **Fabric**: Fabric API + LibJF
- **NeoForge**: LibJF

(Cloth Config API may also be required depending on your setup — check the [Respackopts page](https://modrinth.com/mod/respackopts) for the exact list.)

## How to Use

1. Install Respackopts and its dependencies into your `mods` folder (matching your loader)
2. Enable this resource pack
3. Open the gear icon next to the pack in the resource pack list, and turn ON only the blocks you want rainbow-colored (everything is OFF by default)

Feel free to use this pack in gameplay videos and livestreams.
